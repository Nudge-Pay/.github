# Nudge Pay

**Contactless payment requests with a self-custodial wallet and passkey access on Stellar.**

Nudge explores what a payment request feels like when it travels over NFC: a receiver prepares a request, a payer approves it, and both devices watch the network confirm.

## What we build

- **Request by tap** — A receiver shares a Stellar request — address, asset, amount, expiry — over NFC.
- **Self-custodial by default** — Keys and passkey access stay with the user; Nudge never holds funds.
- **Client and server, open** — An Expo / React Native client paired with a NestJS API, both built on the Stellar SDK.
